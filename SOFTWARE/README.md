## What is the Portal Interface Engine?

PIE is the operating system that Lamoka models run on, it provides simple "portals" to whatever you would like with your unit. 


## Compatibility

 PIE versions v1.8 and below will work on the Lamoka1-DEV-Brain (v1.8 working the best). Due to the inclusion of voltage, temperature, and current monitoring on the ADC pins of the Lamoka1, we cannot fully guarantee succesful operation of anything over v1.8 on the Lamoka1-DEV-Brain.

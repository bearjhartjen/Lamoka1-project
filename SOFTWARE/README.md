## What is the Portal Interface Engine?

PIE is the operating system that Lamoka models run on. It provides simple "portals" to whatever you would like with your unit. 


## Compatibility

 PIE versions v1.8 and below will work on the Lamoka1-DEV-Brain (with v1.8 working best). Due to the inclusion of voltage, temperature, and current monitoring on the ADC pins of the Lamoka1, we cannot fully guarantee successful operation of anything newer than v1.8 on the Lamoka1-DEV-Brain.
